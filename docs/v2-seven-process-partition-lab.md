# V2 seven-process minority-loss and rejoin laboratory

**Scope:** same GitHub-hosted runner; seven independently keyed V2 OS validator processes over libp2p QUIC, one unkeyed observer. This experiment does **not** establish multi-host independence, real provider/ISP partition behavior, production performance, or rollback-resistant key custody.

The `V2 4-7 Process Signed QC Lab` workflow runs a distinct *ephemeral* seven-validator fixture after its existing two-height certified finality and intentionally corrupt-history observer test. The partition fixture keeps all P-256 private keys, genesis, world state and signing journals in a private runner temp root excluded from all artifacts. First, it forms a signed height-one QC with seven validators and verifies that every validator and the nonvoting observer finalized the same header.

The local **read-only owner-only Unix socket** exposes the actual round-zero scheduled proposer; the orchestrator chooses three *different* validators to terminate via `SIGKILL`, leaving the scheduled proposer among four survivors. The next `/propose` must return `ErrNoQuorum` (5 of 7 required) and every survivor plus the observer must stay at certified height one. **The test must not pass merely because the proposer is offline**. After termination, the harness removes only stale 0600 test-control sockets in the private fixture directories, never the signing journals; it restarts the three processes with their original P-256 signing keys, durable journal and certified world state. The harness checks certified recovery at height one, repins all current libp2p peer IDs, reconnects seven validators and the unkeyed observer, and retries the same height-two signing target. All seven validators plus the observer must then commit the same height-two certificate with at least five valid votes.

Artifacts retain only process/peer identities, exact code revision, header hashes, phase outcomes and nonsecret stderr diagnostics. This is a deliberately adversarial **single-host minority-offline** scenario; it does not yet prove packet-loss/reordering tolerance, cross-runner network recovery, replay protection against cloned signer keys, or full multi-round BFT unlocking. #211, #226, #229 and mainnet #42 remain open until their remaining acceptance requirements are satisfied.
